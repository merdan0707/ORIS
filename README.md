- HomeWork_3: Работа со статическими файлами, HTTP-заголовками и MIME-типами. Обработка 404. Вёрстка Rockstar.

- HomeWork_7: Выделение Framework в библиотеку классов. Разработка собственного HTML-шаблонизатора, условия и циклы.     
- HomeWork_8: Модульное тестирование MSTest. Покрытие HTTP-фреймворка и HTML-шаблонизатора тестами.     
- HomeWork_9: ADO.NET. Разработка собственной мини-ORM: универсальные INSERT, UPDATE, DELETE и модульные тесты.
- HomeWork_10: HTTP Cookie. Пользовательские сеансы, аутентификация и [Authorize]. Реализации и покрытие тестами.
